# Private Atelier Emine seller review

Staging only. `/supplier-review/atelier-emine#token=…` opens a standalone review page with no admin login, shop navigation or analytics. The URL fragment is removed from visible browser history immediately and exchanged by same-origin POST for an eight-hour HttpOnly, SameSite=Strict session cookie scoped to the supplier review API. Only SHA-256 token and session hashes are stored. The page and API use no-store, no-referrer and noindex headers.

A seven-day invitation has been prepared for the owner-authorized handoff. Its fixture contains only a random token's hash, not the token. It is inserted once with a stable ID; restarts never reactivate a revoked invitation. The owner receives the private URL separately. No email or message is sent automatically. Admin can revoke all supplier review access or generate a replacement seven-day link, invalidating prior links and sessions. Newly generated links are shown once, so copy them before leaving the page.

The supplier can see only the imported Atelier Emine draft collection, its public-style profile information and supplied metadata/photo links. No staff review notes, customer/order data, credentials or other designer data are exposed. No seller account is provisioned. The reviewer supplies their name, business email and authorization declaration, then confirms each listing explicitly or requests changes with a required note. All responses are append-only and include the listing content digest and time. Private-link access and claimed identity are not verified seller identity or payment-provider approval.

Supplier responses appear separately from staff notes in `/admin#atelier-emine-drafts`. Each response is bound to the exact title, description, USD price and source details reviewed. A later content change invalidates the apparent confirmation; stale writes return 409. Responses never update listing or moderation status, seller terms, identity, payout readiness, inventory, public visibility or checkout. All remain private drafts with an inactive placeholder profile.

The seller page uses the supplied photo links and supports search/filtering, per-item confirmation, change requests and progress counts. Notes typed into a card survive search/filter changes in memory, but only submitted responses persist. Refresh warns about unsaved notes. Cookie sessions can resume without retaining the raw fragment token in browser storage; after session expiry, reopen the original link while it is still valid.

Validation covers full lifecycle, restricted access, origin checks, hash-only storage, session scope, no admin/seller account access, production exclusion, link expiry/replacement/revocation, stale content, item scope and unchanged public/checkout state. Seller review does not resolve the Turkish payout-provider blocker.
